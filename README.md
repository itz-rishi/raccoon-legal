# Raccoon Neon Website

A responsive, single-page website for the Raccoon Discord bot, styled to match the black, neon-green, and white logo.

## Files
- `index.html` — website source
- `raccoon-logo.png` — supplied Raccoon logo used in the header and hero

## Run locally
Open `index.html` in a browser. Keep `raccoon-logo.png` in the same folder.

## Deploy to Vercel
1. Upload both files to the same GitHub repository root.
2. In Vercel, choose **Add New → Project** and import the repository.
3. For a plain HTML site, leave the framework preset as **Other** and leave build/output settings empty unless prompted otherwise.
4. Deploy.

The Terms and Privacy sections are templates and should be checked against the bot's actual implementation and data practices before publication. The Interactions Endpoint URL and Linked Roles Verification URL should only be configured if those server endpoints are implemented.
