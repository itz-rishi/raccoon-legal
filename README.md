# Raccoon — Anonymous Devs

A polished, responsive, single-page website for the Raccoon Discord bot. Includes the four Discord application information categories:

1. Interactions Endpoint URL guidance
2. Linked Roles Verification URL guidance
3. Terms of Service
4. Privacy Policy

Also includes Raccoon invite, support server, and owner contact links, responsive styling, subtle motion, and reduced-motion accessibility support.

## Deploy on GitHub Pages
1. Create a repository, for example `raccoon-legal`.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then save.
5. Once published, your website will be available at `https://YOUR-GITHUB-USERNAME.github.io/raccoon-legal/`.

## Discord Developer Portal URLs
Replace `YOUR-GITHUB-USERNAME` and repository name with your real values:
- Terms of Service: `https://YOUR-GITHUB-USERNAME.github.io/raccoon-legal/#terms`
- Privacy Policy: `https://YOUR-GITHUB-USERNAME.github.io/raccoon-legal/#privacy`
- Interactions Endpoint URL: leave blank for a standard Discord Gateway bot.
- Linked Roles Verification URL: leave blank unless a real verification endpoint is implemented.

## Before publishing
Review the legal text against the bot's actual data collection, storage, logging, retention, and deletion practices. The site is informational and does not implement interaction handling or Linked Roles verification. It is not legal advice.
